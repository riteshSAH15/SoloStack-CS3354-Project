## Project Information

This repository is for the CS 3354 Object-Oriented Programming semester project.

For Phase 1, the project will be a console-based **Task and Study Planner**. It will manage tasks, priorities, deadlines, completion status, and recurring work while demonstrating inheritance, polymorphism, encapsulation, packages, and object collaboration.

The project will be designed so the core logic can be reused in Phase 2 when a graphical user interface is added.
